# JPA / Hibernate / Spring Data Capstone Project

## Features
- Spring Boot REST APIs
- JPA & Hibernate
- CRUD Operations
- MySQL Database
- Repository Layer
- Service Layer
- Controller Layer
- Entity Relationships
- Pagination Support

## Technologies
- Java 17
- Spring Boot 3
- Hibernate
- Spring Data JPA
- MySQL
- Maven

## Run Project

```bash
mvn spring-boot:run
```

## API Endpoints

GET /employees
POST /employees
PUT /employees/{id}
DELETE /employees/{id}# jpa-hibernate
